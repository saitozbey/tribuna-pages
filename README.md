# Tribuna Pages

Tribuna mobil uygulamasının Türkçe gizlilik ve destek sayfaları.

- Gizlilik: https://saitozbey.github.io/tribuna-pages/
- Destek: https://saitozbey.github.io/tribuna-pages/support.html
- Alternatif gizlilik yolu: https://saitozbey.github.io/tribuna-pages/privacy.html

Geliştirici: Sait Özbey · İletişim: ozbeyglobal@gmail.com

GitHub Pages kaynağı: `main` dalı, depo kökü. Derleme veya bağımlılık gerekmez.
`index.html` gizlilik politikasıdır. İçerik değiştiğinde `privacy.html` kopyasını
ve güncelleme tarihini de güncelleyin. `styles.css` her iki sayfada ortaktır.

Metin, 17 Ekim 2026 tarihindeki Tribuna kaynak koduna göre hazırlanmıştır.
Reklam/bildirim işleme açıklamaları bu özelliklerin etkin olduğu sürümler için
koşullu yazılmıştır; release reklamları şu an uygulamada kapalıdır. Yayın
öncesinde gerçek SDK yapılandırması, yaş hedeflemesi, mağaza gizlilik beyanları,
saklama uygulamaları ve onay seçenekleriyle metnin eşleşmesi gözden geçirilmelidir.
Bu sayfaların yayımlanması tek başına mağaza veya mevzuat uygunluğu garantisi değildir.
